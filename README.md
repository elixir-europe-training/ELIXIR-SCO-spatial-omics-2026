# NBIS/ELIXIR Spatial Omics Data Analysis

This repository contains the material for the NBIS and ELIXIR Single Cell Omics (SCO) Community course **Spatial Omics Analysis** held in Uppsala, Sweden, Oct 6th-9th 2026. The rendered view of this repository is available [here](https://elixir-europe-training.github.io/ELIXIR-SCO-spatial-omics-2026/).

The course was hosted by the [National Bioinformatics Infrastructure Sweden (NBIS)](https://www.nbis.se) and the [ELIXIR Single Cell Omics Community](https://elixir-europe.org/communities/single-cell-omics). It reuses many of the materials from the [previous instance of the course (January 2025)](https://elixir-europe-training.github.io/ELIXIR-SCO-spatial-omics/) hosted at the [Swiss Institute for Bioinformatics](https://https://www.sib.swiss/).

The materials published for this course are intended to facilitate knowledge transfer to anyone and by anyone. Course organizers are welcome to use the materials in their own courses. If you do, please credit the original authors of the materials.

## Contents

The course consists of 9 lectures and 9 practical exercise sessions. The [schedule](https://elixir-europe-training.github.io/ELIXIR-SCO-spatial-omics-2026/schedule.html) on the website contains links to the presentation slides and notebooks with the results of the exercises. To run the exercises, we recommend following the [instructions on the website](https://elixir-europe-training.github.io/ELIXIR-SCO-spatial-omics-2026/practicals.html) (["Working locally"](https://elixir-europe-training.github.io/ELIXIR-SCO-spatial-omics-2026/practicals.html#option-2-working-locally)).

If you wish to run the exercises in your own environment, you can use [`docker/download_labs.sh`](docker/download_labs.sh) to download the notebooks and datasets, or get the notebooks from the [`practicals` directory](practicals) and the datasets from the links in [`docker/practical_data.tsv`](docker/practical_data.tsv).

## Improvements

To facilitate future instances of the course, improvements are pushed to the `fix/after_course` branch rather than the `main` branch. This branch will address some of the issues identified during the course, for example by reducing the resource requirements. The `main` branch reflects the state of the course website at the time of hosting the course with only minor modifications.
