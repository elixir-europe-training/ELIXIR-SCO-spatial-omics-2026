# Practical HTML Reports

This folder contains rendered HTML outputs for the practicals.

These files are too large for GitHub to render in the browser. Clicking a
file will open GitHub's file viewer, and clicking "Raw" will only show the
raw HTML source as plain text instead of rendering it. To view a report
properly, you need to download it and open it locally in your browser.

## Option 1: Download a single file

1. Open the file on GitHub (e.g. `p6_alignment.html`).
2. Click the download button in the top-right corner of the page.
3. Save the page to your computer
4. Make sure it saves with an `.html` extension (not `.txt`).
5. Open the saved file by double-clicking it, or drag it into your browser
   window.

## Option 2: Clone the whole repository

If you want all the practical files at once:

```bash
git clone https://github.com/elixir-europe-training/ELIXIR-SCO-spatial-omics-2026.git
cd ELIXIR-SCO-spatial-omics-2026/practicals_html
```

Then open any of the `.html` files directly in your browser.

## Note

Do not try to view these files using GitHub's "Raw" link directly in the
browser tab it opens in, browsers often render large raw HTML as plain
text rather than executing it, since GitHub serves raw files with a
`text/plain` content type. Downloading and opening the file locally avoids
this issue.
